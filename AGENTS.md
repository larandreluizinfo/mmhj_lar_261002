# AGENTS

## Regra obrigatória de versionamento

Toda alteração feita neste repositório DEVE ser commitada e pushada.

- Após qualquer criação, edição ou remoção de arquivos, execute:
  1. `git add -A`
  2. `git commit -m "<mensagem clara do que mudou>"`
  3. `git push origin main` (ou para a branch atual, se for diferente de `main`)
- Nunca deixe alterações apenas locais sem commit + push.
- Se o push falhar, resolva (pull/rebase) e tente novamente até o repositório remoto estar atualizado.
- O GitHub Pages está ativo na branch `main`; somente alterações pushadas entram no ar.
